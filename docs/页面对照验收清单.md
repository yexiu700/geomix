## 4. 本地与 CI 执行方式

1. **准备基础设施与种子数据**：
   ```bash
   pnpm build
   pnpm db:migrate
   pnpm db:seed
   ```
2. **启动 E2E 后端（API + BullMQ Worker + 公开文章测试桩）与前端服务**：
   Playwright 配置 `playwright.config.ts` 在未设置 `E2E_SKIP_WEBSERVER=1` 时自动拉起后端与前端服务；也可手动运行：
   ```bash
   pnpm test:e2e
   ```
3. **产物检查**：
   - HTML 报告：`playwright-report/`
   - GeoMix 实测截图：`test-results/e2e-screenshots/`
   - 清单完整性与合规单测：`pnpm --filter @geomix/shared test`

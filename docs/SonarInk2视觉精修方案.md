# GeoMix 视觉精修方案：Sonar Ink 2.0「沉静精确」

> **追踪总纲**：Epic #395（Batch 0 `#390` / Batch 1 `#391` / Batch 2 `#392` / Batch 3 `#393` / Batch 4 合并入 `#384` / Batch 5 `#394`，并协同 `#385` 与 `#388`）。

## 目标

对照线上页面走查与代码审计后的结论是：**视觉杂乱感的问题不在配色，而在系统**。深色 Sonar Ink 的底子是对的，但页面缺少统一的布局容器、字号阶梯、层级表达方式和操作收纳规则，每个组件都在自己画边框、写字号、配颜色，叠加起来就显得嘈杂。

本方案不推翻现有深色视觉，而是把「精致感」拆成可度量的规则，先打地基（设计令牌 2.0 与 7 个基础原语），再逐页重排，最后用 CI 守卫棘轮防止回潮。**不改业务逻辑、不改后端接口、不改数据结构**。

### 1.2 杂乱感的 7 个根因

| #   | 根因                             | 页面中的典型表现                                                                                         |
| :-- | :------------------------------- | :------------------------------------------------------------------------------------------------------- |
| 1   | **没有布局容器**                 | `/home` 文章行标题在最左、状态标签在最右，宽屏下视线要横跨整屏；KPI 卡被拉得很宽但内容很少               |
| 2   | **用边框表达层级（框中框）**     | `/brands`：页面卡 → 分节卡 → 子卡 → 输入框，四层描边；`/home` 每个区块都是带边框的大卡                   |
| 3   | **字号太小、阶梯太多、对比太弱** | 大量 11–12px 中文辅助说明；标题和正文字重差别小；每个标题下都跟一行灰色说明文字                          |
| 4   | **强调色泛滥，失去焦点**         | Phosphor 亮绿同时用在主按钮、选中态、标签、导航、KPI 顶线；同一行文章里出现黄、绿、灰、青 4 种标签       |
| 5   | **操作全部外露**                 | `/home` 每行常驻重按钮；`/brands` 每个竞品、每条问句后面都有红框「移除」；`/studio` 工具栏全是带边框按钮 |
| 6   | **局部信息过载**                 | `/studio` 顶部 16 个黄色 `[TBD]` 胶囊铺满两行；右栏 GEO 体检、合规、状态、交付、发布登记纵向堆叠         |
| 7   | **外壳噪音**                     | 顶栏 8 个元素；面包屑与左侧导航、页面标题重复；分节标题带「1.」「2.」编号像表单文档                      |

## 二、设计方向与原则

**方向**：保留深色 Sonar Ink 与 Phosphor 品牌色，向「沉静精确」靠拢，通过清晰的表面深浅层次、克制的单层微光描边、规范字号与渐进式操作显露提升精致度。

| 原则                    | 规则                                                                                                                    |
| :---------------------- | :---------------------------------------------------------------------------------------------------------------------- |
| **P1 留白优先于线条**   | 层级用间距和底色深浅表达；一个视图内**最多一层描边**；分节之间用 24–32px 间距而非边框                                   |
| **P2 一个视图一个焦点** | Phosphor 只用于：每个区域唯一的主按钮、焦点环、导航激活指示条、关键数据高亮。选中态改用中性浅色底                       |
| **P3 状态有词汇表**     | 所有状态统一为「圆点 + 文字」的 `StatusBadge`，只允许 5 种语义（成功 / 进行中 / 警告 / 危险 / 中性）；每行最多 2 个标签 |
| **P4 操作渐进显露**     | 行内次要操作悬停显示或收进「⋯」菜单；删除类危险操作一律进菜单并二次确认，不再常驻红框按钮                               |
| **P5 可读的字号阶梯**   | 中文最小 12px；正文 14px；只保留 7 级字号；编辑器正文 15px、行高 1.75、行宽 ≤ 720px                                     |
| **P6 内容有边界**       | 看板类页面最大宽 1360px，表单类页面最大宽 1040px，阅读区最大宽 720px，居中对齐                                          |

## 三、设计令牌 2.0

在现有 `--gm-*` 体系上**增量**扩展，旧变量保留别名，保证零破坏。

```css
:root {
  /* 字号阶梯：7 级，中文最小 12px */
  --gm-fs-xs: 12px;
  --gm-lh-xs: 18px; /* 元信息、辅助说明 */
  --gm-fs-sm: 13px;
  --gm-lh-sm: 20px; /* 表格、紧凑控件 */
  --gm-fs-md: 14px;
  --gm-lh-md: 22px; /* 正文、表单 */
  --gm-fs-lg: 16px;
  --gm-lh-lg: 24px; /* 分节标题 */
  --gm-fs-xl: 20px;
  --gm-lh-xl: 28px; /* 页面标题 */
  --gm-fs-2xl: 28px;
  --gm-lh-2xl: 34px; /* KPI 数字 */
  --gm-fs-prose: 15px;
  --gm-lh-prose: 26px; /* 编辑器正文 */

  /* 间距：4pt 网格，只用这 7 档 */
  --gm-sp-1: 4px;
  --gm-sp-2: 8px;
  --gm-sp-3: 12px;
  --gm-sp-4: 16px;
  --gm-sp-6: 24px;
  --gm-sp-8: 32px;
  --gm-sp-12: 48px;

  /* 布局容器 */
  --gm-container-wide: 1360px; /* 看板：/home /visibility */
  --gm-container-form: 1040px; /* 设置与表单：/brands /account */
  --gm-measure-prose: 720px; /* 阅读与编辑 */

  /* 层级底色 + 单层轻描边 + 顶边微光（消除框中框，同时保持普通屏清晰轮廓） */
  --gm-surface-0: #090b0a; /* 页面 */
  --gm-surface-1: #111513; /* 区块 */
  --gm-surface-2: #181d1b; /* 区块内分组、输入框 */
  --gm-surface-3: #202623; /* 浮层、悬停/激活胶囊 */
  --gm-border-outer: rgba(255, 255, 255, 0.065);
  --gm-border-inner: rgba(255, 255, 255, 0.06);
  --gm-specular-top: inset 0 1px 0 rgba(255, 255, 255, 0.045);

  /* 前景色阶（校准至 WCAG AA，消除暗灰发闷） */
  --gm-fg-1: #eef2f0;
  --gm-fg-2: #adb6b2;
  --gm-fg-3: #838d89; /* 在 #111513 上对比度 ≥ 5.2:1 */
  --gm-fg-4: #5e6864; /* 占位符与空值 — 保持可读 */

  /* 强调色角色 */
  --gm-accent: var(--gm-phosphor); /* 仅当前最重要下一步的主按钮、焦点、激活指示 */
  --gm-selected-bg: rgba(255, 255, 255, 0.07); /* 选中态改为中性 */
  --gm-selected-fg: var(--gm-fg-1);
}
```

AntD 主题与字体策略（`apps/web/lib/design-tokens.ts` + `apps/web/app/layout.tsx`）：

- **AntD 控件维持 `fontSize: 13`**（避免表格、窄屏按钮、双列配置项产生折行回归），仅将卡片主文案与阅读说明升级为 `14px`、写作台正文升级为 `15px / 1.75 行高`。
- **自托管字体子集**：在 `apps/web/public/fonts/` 内置轻量 WOFF2（`Inter` + `JetBrains Mono`），不依赖外部 CDN，确保 Windows 与 macOS 环境下英文标题与等宽数字锐利统一。

## 五、逐页改造

### 5.1 外壳（全站完全统一）

```text
现状  [品牌▾][CN|海外] 行动首页  [公告…]  [搜索⌘K] 运营后台 1,000 点 [收起菜单]
改后  N NordicAudio ▾  [CN 国内 | 海外 GLOBAL]     [⌘K 搜索]  🔔  1,000 点
```

- **顶栏去框化 + 双市场 1 键直切**：品牌切换与点数余额默认无外框（悬停显浅底），顶栏仅保留搜索框与中性分段 `[CN 国内 | 海外 GLOBAL]` 轻描边（维持 `aria-label="切换目标市场"` 零 E2E 回归）；**全站删除多余面包屑**。
- **消除双头像重复**：右上角不放头像，账号入口统一收敛至左侧栏底部（管理员在账户上方保留安静的「运营后台」1 键入口）。
- **写作台可展开 `72px` 图标栏**：进入 `/studio` 时侧栏收敛为 `72px`「图标 + 严格 `12px` 短中文标签（首页/品牌/诊断/写作）」，并在底部提供箭头随状态翻转 `180°` 的「展开 / 收起导航」切换按钮。
- 内容区外层容器统一采用单层 `1px` 轻边框 + 顶边微光，按页面类型套用最大宽度。

### 5.2 行动首页 `/home`

- **诚实 KPI 指标带（严格对齐现有 `ActionHomeResponse['health']` 字段）**：4 张 KPI 卡合并为一条 `KpiStrip`（细竖线分隔），不虚构后端未返回的折线图或分母；`0.0%` 进度条保持完全空轨不造假长度；平均顺位用直白人话说明（如「多数回答将品牌排在第 1 位」）替代抽象刻度。
- **P0 抓取异常上提首屏**：存在已发布页面 HTTP 404 / robots 阻断时，紧贴 KPI 下方展示克制的单行告警条 + `立即排查`，不再埋在页面底部。
- **Top 3 建议空态走真实入口**：改用星光建议图标与安静引导「去写作台自由选题 →」，不虚构未实现接口，也不与页头「发起新一轮监测」重复。
- **近期成稿保持时间倒序 + 分级显露**：严格按更新时间排序不破坏用户预期；高优行动项（`已发布 · 待复测`）通过微暖底色与常驻轻按钮「发起复测」突出，普通草稿右缘紧齐常驻 `⋯`、悬停滑出「继续编辑」。

### 5.3 品牌资产 `/brands`

- 改为设置页布局：左侧分节锚点（基础身份 / 事实卡 / 实拍图库 / 发布渠道），右侧内容区最大宽 `1040px`。
- 去掉「1.」「2.」编号和外层大卡，分节之间用间距分隔，只保留单层底色 + 轻外边框。
- 竞品、种子问句改为紧凑列表，删除改为悬停出现的图标按钮。
- 表单有改动时底部出现吸附的「保存 / 放弃」条，替代每块各自的保存按钮。

### 5.4 可见度诊断 `/visibility`

- KPI 改用 `KpiStrip`，去掉部分卡片上的彩色顶线。
- 图表区统一 12 栅格和统一的图表卡头部（标题、单位、时间范围）。
- 竞品声量条只给本品牌着色，竞品统一中性灰，避免满屏橙红。

### 5.5 GEO 写作台 `/studio`（视觉与布局并入 #384）

- **`100dvh` 三栏独立滚动 + 窄屏抽屉**：左队列、中正文、右体检各自独立滚动；窗口 `≤ 1200px` 收紧侧栏，`≤ 920px` 自动切换为单栏正文 + 工具栏「队列 / 体检」滑出抽屉，绝不压扁。
- **完整保留生成配置能力**：顶部折叠为单行摘要，点击「配置 / 重写 ▾」后完整展开「目标问题 + 4 套文体配方 + 2 种阵地形态 + 高级写作偏好 + 重新生成」，零功能退步。
- **高发现性 AI 改写**：工具栏提供带文字的「✨ AI 改写 ▾」下拉菜单，同时划选正文段落时在选区上方浮出轻量 Bubble Toolbar（`更客观 / 转表格 / 补数据 / 精简直答`）。
- **克制的正文 `[TBD]` + 同名去重合并抽屉**：正文中的 `[TBD]` 平时仅保留虚线下划线、悬停时显柔和底色；侧滑抽屉按同名自动去重合并，填一次替换全篇，底部统一选择反哺分类（与 #385 协同实现）。
- **单主按钮状态机底栏**：右栏底部收敛为「唯一亮绿主按钮 + 一行状态说明」——有未补全事实时主按钮指向「**补齐 N 组待补充事实**」（下方附「仍要预览分发 →」轻文字链）；补齐且通过门禁后主按钮自动切换为「**进入分发工作台**」。
- 正文保持 `15px`、行高 `1.75`、最大行宽 `720px` 居中阅读体验；右栏分为「体检」「交付」双页签。

## 六、防回潮守卫

在 `apps/web/lib/ux-foundation-guard.spec.ts` 增加棘轮检查（只降不升）：

```ts
const VISUAL_DEBT_BASELINE = {
  inlineStyleBlocks: 795, // 每个批次合入后下调
  inlineFontSize: 196,
};

it('forbids font sizes below 12px in components', () => {
  // 扫描 components/**/*.tsx（不含 spec），fontSize < 12 直接失败
});

it('visual debt only ratchets down', () => {
  expect(countInlineStyles()).toBeLessThanOrEqual(VISUAL_DEBT_BASELINE.inlineStyleBlocks);
  expect(countInlineFontSize()).toBeLessThanOrEqual(VISUAL_DEBT_BASELINE.inlineFontSize);
});
```

同时禁止在组件里使用 AntD 预设色（`geekblue`、`gold` 等），状态颜色只能走 `StatusBadge`。

## 九、已确认的架构与设计决定（v3 定稿）

| 决策项                 | 结论                                                                                                                                                                                             |

- `@geomix/config` ← 所有包（devDependencies）
- `@geomix/shared` ← `@geomix/db`、`@geomix/server`、`@geomix/web`
- `@geomix/prompts` ← `@geomix/db`
- `@geomix/db` ← `@geomix/server`

## 3. 后端架构（`apps/server`）

### 3.1 双进程入口与基础设施

- **API 进程**：`src/main.api.ts` → `createApiApp()`（`common/create-api-app.ts`）→ `ApiModule`，全局路由前缀 `/api/v1`，注册 `AuthContextMiddleware` 与 `ApiExceptionFilter`。
- **Worker 进程**：`src/main.worker.ts` → `WorkerModule` → `QueueModule.forWorker()`，消费 7 个 BullMQ 队列，优雅关闭等待当前单元落盘。
- **核心公共层**：
  - `prisma/prisma.service.ts`：同时暴露 `prisma.scoped`（按 `AsyncLocalStorage` 自动注入 `tenantId`）与 `prisma.base`（无自动过滤）。
  - `tenant/tenant-context.ts`：`runInTenant` / `currentTenantId`。
  - `auth/`：`AuthContextMiddleware`、`AuthGuard`（401）、`TenantActiveGuard`（到期/停用写接口 403 / `40301`）、`access-policy.ts`。
  - `billing/`：`BillingService`（冻结/结算/退回/对账）、`QuotaService`、`AdminGuard`（非管理员返 404）。
  - `common/`：`ApiError`、`ApiExceptionFilter`、`parseBody`、`createApiApp`、`test-db.ts`（隔离测试库工具）。

| `admin/` | `/admin` | 租户开户/编辑/配额、价格表、公告、系统模板、LLM 成本日报（`/admin/llm-costs`） |

### 3.3 异步队列与 Worker Runners（7 个队列）

定义在 [`packages/shared/src/queue.ts`](../packages/shared/src/queue.ts)，注册在 [`apps/server/src/queue/queue.module.ts`](../apps/server/src/queue/queue.module.ts)：

| 队列名 | 每租户并发上限 | 默认全局并发环境变量 | 对应 Runner |
| --- | ---: | --- | --- |
| `write-article` | 2 | `QUEUE_WRITE_CONCURRENCY` (4) | `AiTaskRunner`（`job.name='ai-task'`，其余回退 `WorkDriver`） |
| `rewrite-single` | 5 | `QUEUE_REWRITE_CONCURRENCY` (5) | 队列已注册（`WorkDriver` 兜底）；单篇复刻主流程由 `RewritesService` 在 API 进程内直接执行 |
| `rewrite-batch` | 1 | `QUEUE_BATCH_CONCURRENCY` (2) | `RewriteBatchRunner` |
| `kb-index` | 2 | `QUEUE_KB_CONCURRENCY` (2) | `KnowledgeIndexRunner` |
| `image-gen` | 2 | `QUEUE_IMAGE_CONCURRENCY` (2) | `ImageJobRunner` |
| `visibility-check` | 2 | `QUEUE_VISIBILITY_CONCURRENCY` (2) | `VisibilityRunRunner`（配 `VisibilityCollectorService` + `VisibilityJudgeService`） |
| `maintenance` | 1 | 固定 1 | `MaintenanceRunner`（定时对账释放孤儿冻结 + 过期租约恢复） |

### 3.4 外部适配层（`apps/server/src/infra/`）

由 `AdaptersModule` 统一提供给 API 与 Worker，**开发与 CI 默认全部走确定性假实现、零外网调用**：

- `llm.ts`：`LlmService`（支持 DeepSeek / 通义 / 豆包 OpenAI 兼容协议路由与主备回退；`LLM_PROVIDERS={}` 时返回 `【FAKE】` 占位；记录占位微元成本，不扣点数钱包）。
- `embedding.ts`：`EmbeddingService`（固定 `1024` 维，与 `KnowledgeChunk.embedding vector(1024)` 对齐；`EMBEDDING_PROVIDER=fake` 时按文本哈希生成确定性向量）。
- `image.ts` + `compress.ts`：`ImageService`（`IMAGE_PROVIDER=fake` 输出纯色占位图；输入上限 100MB / 1600 万像素，长边缩至 1600、JPEG <= 1MB、自动去 EXIF）。
- `storage.ts`：`StorageService`（`STORAGE_DRIVER=memory` 默认进程内存；`STORAGE_DRIVER=s3` 连接 MinIO/S3，键前缀 `tenants/{tenantId}/`）。
- `search.ts`：`SearchService`（默认 `link_list` 链接清单去参去重；`remote` 模式调用受控搜索网关）。
- `public-fetch.ts` + `ssrf.ts` + `guarded-request.ts`：`PublicFetchService`（SSRF 校验 + DNS 钉住 + 最多 3 次重定向校验 + `robots.txt` 缓存 + 5MB / `text/html` 限制）。
- `compliance.ts`：`ComplianceService`（禁做行业拦截返回 `403` / `40302` 并写 `AuditLog`、敏感词与极限词分级替换/打标）。

## 4. 前端架构（`apps/web`）

### 4.1 路由总览

- **认证入口**：`/login`（登录页，含服务端 PNG 验证码与限流提示），`/` 跳转工作台或登录。
- **控制台多标签壳（`app/(console)/` → `ConsoleShell` → `ModuleScreen`）**：
  - 首页：`/dashboard`
  - AI 创作 - 素材源力：`/material/keywords`、`/material/questions`（`?keywordId=`）、`/material/gallery`、`/material/gallery/[id]`、`/material/knowledge`
  - AI 创作 - 文章写作：`/writing/prompts`、`/writing/categories`、`/writing/tasks`（`?keywordId=`）、`/writing/articles`（`?categoryId=&taskId=`）
  - AI 创作 - 流量复刻：`/rewrite/single`、`/rewrite/batch`
  - AI 创作 - AI 生图：`/image`（受 `FEATURE_AI_IMAGE` 控制）
  - AI 可见度：`/visibility/overview`（`?profileId=`）、`/visibility/monitors`（`?profileId=&runId=`）（受 `FEATURE_VISIBILITY` 控制）
  - 个人中心：`/me/points`、`/me/money`、`/me/rights`、`/me/verify`
  - 开发验收样板：`/workbench/samples`（仅非生产环境管理员可访问）
- **管理后台（`app/admin/`，独立布局）**：
  - `/admin/tenants`、`/admin/pricing`、`/admin/announcements`、`/admin/templates`、`/admin/llm-costs`（`/admin` 自动跳 `/admin/tenants`；非管理员拦截提示无权/不存在）。
- **历史路径重定向（`middleware.ts` + `lib/route-map.ts`）**：
  - 已登记 16 条 `/user/*` 旧入口（覆盖全部 15 个历史业务路径，含 `/user/quanyi` 与 `/user/account_rights` 别名），经 `NextResponse.redirect`（保留查询参数）重定向到对应英文语义路由，兼容尾斜杠和 `/index`。

## 5. 数据模型与租户隔离分类（`packages/db`）

当前 [`schema.prisma`](../packages/db/prisma/schema.prisma) 共 **34 个模型**（由 `schema-contract.spec.ts` 守卫），按业务域分组如下：

| 业务域 | Prisma 模型 |
| --- | --- |
| 租户、账号与治理 | `Tenant`、`User`、`Verification`、`AgreementSignature`、`Announcement`、`AuditLog` |
| 钱包、配额与计费 | `Wallet`、`Quota`、`PricingItem`、`PointReservation`、`PointLog`、`MoneyLog` |
| 素材源力 | `Keyword`、`Question`、`MediaCategory`、`MediaAsset`、`KnowledgeBase`、`KnowledgeChunk`（含 `vector(1024)` + HNSW 索引） |
| 文章写作 | `PromptTemplate`、`ArticleCategory`、`AiTask`、`AiTaskItem`、`Article` |
| 流量复刻与生图 | `RewriteBatch`、`RewriteRecord`、`AiImageJob` |
| AI 可见度监测 | `VisibilityProfile`、`VisibilityRun`、`VisibilityObservation`、`VisibilityCitation` |
| 通用队列与样板 | `WorkRun`、`WorkUnit`、`ActiveWork`、`CrudSample` |

### 租户隔离分类（[`packages/db/src/tenant-scope.ts`](../packages/db/src/tenant-scope.ts)）

- **`REQUIRED_TENANT_MODELS`（27 个）**：`User`、`Wallet`、`Quota`、`PointReservation`、`PointLog`、`MoneyLog`、`Verification`、`AgreementSignature`、`Keyword`、`Question`、`MediaCategory`、`MediaAsset`、`KnowledgeBase`、`ArticleCategory`、`AiTask`、`Article`、`RewriteBatch`、`RewriteRecord`、`AiImageJob`、`WorkRun`、`WorkUnit`、`ActiveWork`、`CrudSample`、`VisibilityProfile`、`VisibilityRun`、`VisibilityObservation`、`VisibilityCitation`。
- **`NULLABLE_TENANT_MODELS`（1 个）**：`PromptTemplate`（读包含 `tenantId = null` 的系统模板与本租户模板；写操作只允许改动本租户记录）。
- **`UNSCOPED_OPTIONAL_TENANT_MODELS`（1 个）**：`AuditLog`（登录撤销记录按 `userId` 读，不自动过滤）。
- **`UNSCOPED_UNOWNED_MODELS`（5 个）**：`Tenant`、`PricingItem`、`Announcement`（全局/租户主表），以及 **`KnowledgeChunk`、`AiTaskItem`（无 `tenantId` 子表，访问前必须先验证父记录属于当前租户！）**。

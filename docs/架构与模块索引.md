包依赖流向（单向无环）：

- `@geomix/config` ← 所有包（`devDependencies`）

- `@geomix/prompts` ← 独立保留包（一期模板与渲染工具，不再由 `@geomix/db` 或 `@geomix/server` 引用）

## 3. 后端架构（`apps/server`）

### 3.1 双进程入口与基础设施

- **API 进程**：`src/main.api.ts` → `createApiApp()`（`common/create-api-app.ts`）→ `ApiModule`，全局前缀 `/api` + URI 版本控制（`defaultVersion: '1'`、`prefix: 'v'`），同时服务 `/api/v1/*`（基础/管理接口）与 `/api/v2/*`（GeoMix 2.0 核心业务域），注册 `AuthContextMiddleware` 与 `ApiExceptionFilter`。
- **Worker 进程**：`src/main.worker.ts` → `WorkerModule` → `QueueModule.forWorker()`，消费 **5 个** BullMQ 队列，优雅关闭等待当前单元落盘。
- **核心公共层**：
  - `prisma/prisma.service.ts`：同时暴露 `prisma.scoped`（按 `AsyncLocalStorage` 自动注入 `tenantId`）与 `prisma.base`（无自动过滤）。`prisma.base` 的使用面由 `prisma/prisma-base-allowlist.ts` 白名单加棘轮基线约束，`prisma-base-usage.spec.ts` 负责 AST 校验。
  - `tenant/tenant-context.ts`：`runInTenant` / `currentTenantId`。
  - `auth/`：`AuthContextMiddleware`、`AuthGuard`（401）、`TenantActiveGuard`（到期/停用写接口 403 / `40301`）、`access-policy.ts`。
  - `billing/`：`BillingService`（冻结/结算/退回/对账）、`QuotaService`、`AdminGuard`（非管理员返 404）。
  - `common/`：`ApiError`、`ApiExceptionFilter`、`parseBody`、`createApiApp`、`FreeActionRateLimiter`（0 点 AI 动作滑动窗口限流）、`SecretBox`（AES-256-GCM 渠道凭据加解密与脱敏）、`test-db.ts`（隔离测试库工具）。

### 3.3 异步队列与 Worker Runners（5 个队列）

定义在 [`packages/shared/src/queue.ts`](../packages/shared/src/queue.ts)，注册在 [`apps/server/src/queue/queue.module.ts`](../apps/server/src/queue/queue.module.ts) 与 [`queue.runtime.ts`](../apps/server/src/queue/queue.runtime.ts)：

| 队列名             | 每租户并发上限 | 全局并发环境变量（默认值）                                                | 对应 Runner 与职责                                                                                                                                                                                                                |
| ------------------ | -------------: | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fact-index`       |              2 | `QUEUE_FACT_INDEX_CONCURRENCY`（回退 `QUEUE_KB_CONCURRENCY`，默认 `2`）   | `BrandFactIndexRunner`（`job.name='fact-index'`）：超长事实卡切分向量化写入 `BrandFactChunk`                                                                                                                                      |
| `geo-batch`        |              2 | `QUEUE_GEO_BATCH_CONCURRENCY`（回退 `QUEUE_WRITE_CONCURRENCY`，默认 `2`） | `GeoBatchRunner`（`job.name='geo-batch'`）：2–20 篇批量 GEO 写作，单篇独立结算/退回                                                                                                                                               |
| `visibility-check` |              2 | `QUEUE_VISIBILITY_CONCURRENCY`（默认 `2`）                                | `VisibilityRunRunner`（配 `VisibilityCollectorService` + `VisibilityJudgeService`，完成后回调 `BriefsAutoGeneratorService` 与 `RetestMetricsHookService`）                                                                        |
| `distribution`     |              2 | `QUEUE_DISTRIBUTION_CONCURRENCY`（默认 `2`）                              | `DistributionRunner`（L1 CMS 异步推文 + IndexNow + 建 `GeoPublishRecord`）与 `VariantJobRunner`（`job.name='variant-generate'`，异步并发生成多渠道变体并单渠道退点）                                                              |

### 3.4 外部适配层（`apps/server/src/infra/`）

由 `AdaptersModule` 统一提供给 API 与 Worker，**开发与 CI 默认全部走确定性假实现、零外网调用**：

- `llm.ts`：`LlmService`（支持 DeepSeek / 通义 / 豆包 OpenAI 兼容协议路由、流式输出与主备回退；`LLM_PROVIDERS={}` 时返回 `【FAKE】` 占位；记录占位微元成本至 `AuditLog`，不扣点数钱包）。
- `embedding.ts`：`EmbeddingService`（固定 `1024` 维，与 `BrandFactChunk.embedding vector(1024)` 对齐；`EMBEDDING_PROVIDER=fake` 时按文本哈希生成确定性向量）。
- `image.ts` + `compress.ts`：`ImageService`（`IMAGE_PROVIDER=fake` 输出纯色占位图；输入上限 100MB / 1600 万像素，长边缩至 1600、JPEG <= 1MB、自动去 EXIF）。
- `storage.ts`：`StorageService`（`STORAGE_DRIVER=memory` 默认进程内存；`STORAGE_DRIVER=s3` 连接 MinIO/S3，键前缀 `tenants/{tenantId}/`）。
- `search.ts`：`SearchService`（默认 `link_list` 链接清单去参去重；`remote` 模式调用受控搜索网关）。
- `public-fetch.ts` + `ssrf.ts` + `guarded-request.ts` + `undici-transport.ts`：`PublicFetchService`（SSRF IPv4/IPv6 校验 + `SSRF_ALLOWLIST` + DNS 钉住 + 最多 3 次重定向校验 + `robots.txt` 缓存 + 5MB / `text/html` 限制）。
- `html-extract.ts` + `pdf-extract.ts`：自研零重依赖网页正文抽取与有界 PDF 文本提取（用于竞品反制与品牌事实卡文档提炼）。
- `compliance.ts`：`ComplianceService`（禁做行业拦截返回 `403` / `40302` 并写 `AuditLog`；双轨合规扫描：`CN` 广告法敏感/极限词与 `GLOBAL` FTC/宣称校验）。

## 4. 前端架构（`apps/web`）

### 4.1 路由总览

- **品牌官网、认证入口与公开协作页**：`/` / `/pricing` / `/demo` / `/guides/*` 与 `/zh/*`（双语品牌官网）；`/login`（登录页）；`/share/pr/[token]`（独立免登录外部 PR/KOL 供稿单）；`/share/report/[token]`（v2.2 独立免登录白标月度 GEO ROI 报告页，纯 EN/CN + 打印转 PDF）。
- **控制台极简 6 工作区（`app/(console)/` → `ConsoleShell` → `ShellFrame`）**：
  - 首页：`/home`（`?brandId=&market=`，单主 CTA `发起监测` + `MoreMenu` 溢出操作、`HomeHealthStrip` 指标条、P0 抓取告警、Top 3 写作建议、近期成稿与单行式 `HomeDistributionSummary`）
  - 品牌：`/brands`（`?brandId=&market=`，身份/双市场/产品线配置、统一 `AI 补全`、4 块事实卡 + AI 提炼、品牌素材库、9 个 L1 渠道连接配置；Chrome 扩展配对已收口至 `/account?tab=extension`）
  - 诊断：`/visibility`（`?brandId=&market=&tab=&runId=`，3 个短标签 Tab `总览 | 监测 | 信源`，含趋优声呐、观测问答、引用源追踪与 4 层 Near-Miss 一键补强）
  - 写作：`/studio`（`?brandId=&market=&briefId=&articleId=&batchJobId=&fixCode=&locateTerm=`，专注选题/批量生成、流式精写、`[TBD]` 补填、5 维 GEO 体检与双轨合规，支持平滑前往 `/publish`）
  - 发布：`/publish`（`?brandId=&market=&articleId=&tab=distribute|tracking`，2 个主 Tab `分发 | 追踪` + 页头 `导出` 交付包弹窗，承接 `PublishAttributionSummary` 的 DiD/Wilson 置信归因、月度复测预算进度、待复测提醒与渠道归因表，及 1→N 异步变体与 PR 供稿单）
  - 点数与权益：`/account`（`?brandId=&market=&tab=points|rights|extension`，3 个短标签 Tab `点数明细 | 账号权益 | 扩展配对`，点数支持自动防抖筛选与 CSV 导出，实名与重复模型收录已从 UI 下线、后端接口保留）
- **管理后台（`app/admin/`，独立布局，5 个页面）**：
  - `/admin/tenants`、`/admin/pricing`、`/admin/announcements`、`/admin/llm-costs`、`/admin/leads`（`/admin` 自动跳 `/admin/tenants`；非管理员拦截提示无权/不存在）。
- **兼容重定向（`middleware.ts` + `lib/route-map.ts`）**：
  - 共登记 **23 条 307 重定向**：7 条 v1 控制台旧路由（`/dashboard` → `/home`、`/visibility/overview` & `/visibility/monitors` → `/visibility`、`/me/points` / `/me/money` / `/me/rights` / `/me/verify` → `/account?tab=...`）+ 16 条历史 `/user/*` 入口，保留查询参数并兼容尾斜杠及子路径。
